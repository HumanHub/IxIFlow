# Repository working rules

- Name new Git branches with a conventional prefix such as `work/`, `feature/`, or `fix/`, whichever fits the change. Do not use `codex/`.
- Do not use Docflow for this project.
- Keep commit subjects short, specific, and written in plain technical English. Do not add names, attributions, or tool references.
- For an independent code review, the local Claude Code CLI is at `C:\Users\Avatar\.local\bin\claude.exe`. Use Fable 5.1 at the highest supported effort when available, and keep the review read-only.
