# IxIFlow.Abstractions

Contracts for workflow activity authors: asynchronous execution, recoverable activities, scoped resources, input/output attributes and parallel data combiners. Reference this package from activity libraries.

See the [activity guide](https://github.com/HumanHub/IxIFlow/blob/main/docs/activity-sdk.md) and the [repository](https://github.com/HumanHub/IxIFlow).
