# IxIFlow.Debugging

Optional Debug Adapter Protocol endpoint and pure C# breakpoint conditions for IxIFlow. Enable host debugging through `AddIxIFlow`, then register `AddDebugging` with an application authorizer and a current-user named pipe or authenticated loopback TCP endpoint.

See the [debugging guide](https://github.com/HumanHub/IxIFlow/blob/main/docs/debugging.md) for authorization, inspection and breakpoint behavior.
