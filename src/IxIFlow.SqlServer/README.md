# IxIFlow.SqlServer

SQL Server persistence for IxIFlow instances, checkpoints, catalog, inbox, waits, traces and completion outbox. Register with `services.AddIxIFlow().UseSqlServer(connectionString)` using `IxIFlow.Extensions`.

See the [store guide](https://github.com/HumanHub/IxIFlow/blob/main/docs/stores.md) for database setup and deployment requirements.
