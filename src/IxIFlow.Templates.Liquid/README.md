# IxIFlow.Templates.Liquid

Liquid rendering for IxIFlow templates, implemented with Fluid. Register through `AddIxIFlowTemplates().AddLiquid()` on the IxIFlow builder. Templates use typed models and bounded rendering; filesystem includes and nested renders are refused.

See the [template guide](https://github.com/HumanHub/IxIFlow/blob/main/docs/yaml-authoring.md#template-documents-and-bundled-rendering).
